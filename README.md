# SOS Indicadores de Saúde Mental Estudantil (CIESA — Álgebra Linear II)

Painel computacional interativo em **Python (Streamlit + NumPy + Pandas + Plotly)** para coleta, processamento matricial e visualização de indicadores socioemocionais estudantis.

## Como rodar localmente

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Como hospedar gratuitamente no Streamlit Community Cloud

1. Crie um repositório no GitHub e envie `streamlit_app.py` e `requirements.txt`.
2. Acesse `https://share.streamlit.io/`, faça login com sua conta GitHub e clique em **Create app**.
3. Selecione o repositório, o arquivo principal (`streamlit_app.py`) e clique em **Deploy**.
